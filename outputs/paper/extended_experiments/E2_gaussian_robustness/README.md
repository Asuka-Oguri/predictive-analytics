# E2 - Gaussian Noise Robustness

This experiment evaluates the robustness of the S1-LSBoost model under different levels of additive Gaussian noise.

## Files

- `gaussian_noise_all_runs.csv`: Results from individual experiment runs.
- `gaussian_noise_config.json`: Experiment configuration.
- `gaussian_noise_robustness.png`: Robustness visualization.
- `gaussian_noise_summary.csv`: Aggregated evaluation results.

## Experimental setup

Gaussian noise is added to the scaled test inputs at different noise levels.

The trained model remains unchanged during the evaluation.
