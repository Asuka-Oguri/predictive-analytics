# Data

This directory contains the datasets used in the energy consumption forecasting project.

## Directory structure

- `raw/`: Original, unmodified dataset.
- `processed/`: Processed data generated during preprocessing and feature engineering.

## Source dataset

Dataset: Appliances Energy Prediction

Source: UCI Machine Learning Repository

URL: https://archive.ics.uci.edu/dataset/374/appliances+energy+prediction

Original dataset file: `KAG_energydata_complete.csv`

## Data usage

The raw dataset should remain unchanged.

Processed datasets are derived from the original data and should be reproducible using the notebooks in the `notebooks/` directory.

## Notes

Please cite the original dataset source when using this data.
