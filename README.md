# Predictive Analytics

Dự án lưu trữ các bài tập thực hành môn Phân tích Dự báo.

---

## 📁 Cấu trúc thư mục

* **Week 1/**: Bài tập tuần 1 - Tiền xử lý dữ liệu năng lượng tiêu thụ (Median Imputation, IQR Winsorization, SMOTE Over-sampling, Log Transformation).
* **Week 2/**: Bài tập tuần 2 - Lựa chọn đặc trưng (RFECV) và Giảm chiều dữ liệu (PCA, Truncated SVD, LDA).
* **Dataset/**: Thư mục lưu trữ tập dữ liệu gốc `KAG_energydata_complete.csv` và dữ liệu sau làm sạch `KAG_cleaned_week1.csv`.

---

## 🛠️ Công nghệ sử dụng

* **Môi trường:** Google Colab / Python 3
* **Thư viện:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`, `imbalanced-learn`
